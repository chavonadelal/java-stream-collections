# Задания 1 и 2

Каталог товаров на Java 17+: название, категория, цена и остаток.

- Уровень 1: меню, ручной ввод, загрузка CSV, валидация, обработка ошибок и Stream API (`filter`, `sorted`, `map`).
- Уровень 2: собственный `DynamicArrayList`, совместимый с `List`, с расширением массива и операциями `add`, `get`, `remove`, `size`.

Код находится в `src/main/java/catalog`: `model` содержит товар, `collection` коллекцию, `io` чтение CSV, `service` обработку, `ui` меню. Пример данных: `data/products.csv` в UTF-8, разделитель `;`.

## Запуск

Windows, PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\project.ps1 run
```

Linux, Bash:

```bash
bash scripts/project.sh run
```

## Как проверить

1. Пункт `1`: добавьте товар `Ручка`, `Канцелярия`, `50`, `2`. Пункт `3` покажет его в коллекции.
2. Пункт `2`: укажите `data/products.csv`. Добавятся 5 товаров.
3. Пункт `4`: введите остаток `5`. Получатся Тетрадь, Блокнот и Кружка с ценами 85.50, 120.00 и 350.00 по возрастанию.
4. Пункт `5`, индекс `0`: получите Ручку. Пункт `6`, индекс `0`: удалите ее. Пункт `7` покажет размер `5`.
5. Загрузите CSV еще два раза. Размер станет `15`, что демонстрирует расширение исходного массива емкостью 10.
6. Введите отрицательный остаток или путь к отсутствующему файлу: программа сообщит об ошибке и продолжит работу. Пункт `0` завершает программу.
